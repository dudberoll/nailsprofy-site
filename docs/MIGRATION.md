# Отделение сайта от старого шаблона

Чистая папка создана копированием нужных файлов из прежнего проекта `vibe`. Исходная папка при переносе не изменялась и остаётся резервной копией до отдельного решения владельца.

## Что перенесено

- весь актуальный исходный код Astro-сайта;
- все файлы из `website/public/` и `website/src/assets/`;
- корневые Bun-конфигурация и lockfile;
- Python-скрипты и тесты импорта;
- компактный WordPress-экспорт, нужный импортёру блога;
- актуальные README и инструкции для coding-агентов;
- проектный Codex-навык `ui-refactoring`.

## Что намеренно не перенесено

- Git-история и remotes старого шаблона;
- `_deferred/` с неактивными backend, webapp, mobile и infrastructure;
- старый шаблонный GitHub Actions workflow, который обращался к удалённым частям проекта;
- `node_modules`, Python `.venv`, `.astro`, `dist` и кэши;
- Figma-экспорты и проверочные скриншоты, не используемые работающим сайтом;
- `TASKS.md` старого шаблона;
- исходный WordPress XML размером около 68 МБ: для повторного импорта блога достаточно подготовленного `posts.jsonl`;
- старый шаблонный `LICENSE`, чтобы не назначать сайту лицензию без решения владельца.

## Условие удаления старой папки

Старую папку безопасно рассматривать к удалению только после того, как чистый проект:

1. проходит typecheck и production build;
2. визуально проверен на desktop и mobile;
3. сохранён в отдельном GitHub-репозитории или другой резервной копии;
4. успешно развёрнут из нового репозитория.

До выполнения всех четырёх пунктов исходную папку лучше сохранить.
