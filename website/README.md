# Сайт NailsProfi

Публичный статический сайт на Astro 6 с отдельными React-компонентами для интерактивных блоков.

## Команды

Предпочтительно запускать из корня репозитория:

```bash
bun run dev
bun run check
bun run preview
```

Astro создаёт production-сборку в `website/dist/`. Исходные страницы находятся в `src/pages`, компоненты — в `src/components`, данные — в `src/data`, публичные медиа — в `public`.

Сайт по умолчанию полностью статический. Не добавляйте серверный рендеринг, backend или адаптер без конкретной необходимости.
